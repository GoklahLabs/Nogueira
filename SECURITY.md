# Segurança

Encontrou algum problema de segurança no Afinador Nogueira?

- Escreva para **support@goklahlabs.com.br**, com "Segurança" no assunto.
- Não abra issue pública sobre isso.
- Diga a versão do app, o modelo do celular, a versão do Android e os passos para ver o problema.

Respondemos assim que possível e avisamos quando a correção for publicada.

## Security (English)

Found a security issue in Afinador Nogueira? Email **support@goklahlabs.com.br** with "Security" in the subject, and please do not open a public issue about it. Include the app version, your phone model, the Android version and the steps to reproduce.
